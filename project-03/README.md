# Google Forms 설문 응답 자동 저장 및 조건별 알림

## 1. 프로젝트 개요

교육 프로그램 만족도 설문이 제출되면 응답을 자동으로 분류하고,
Google Sheets에 저장한 뒤 특정 조건에 해당하는 경우
담당자에게 이메일을 보내는 자동화 프로젝트이다.

## 2. 자동화가 필요한 이유

기존에는 담당자가 설문 응답을 직접 확인해야 했다.
따라서 불만족 응답이나 상담 요청을 늦게 발견할 수 있었다.

이를 개선하기 위해 다음 업무를 자동화하였다.

- 설문 응답 수집
- 응답 내용 분류
- Google Sheets 기록
- 담당자 이메일 알림

## 3. 사용 도구

| 구분 | 사용 도구 | 역할 |
|---|---|---|
| 설문 수집 | Google Forms | 만족도 및 상담 요청 수집 |
| 데이터 저장 | Google Sheets | 응답 내용 기록 |
| 자동화 도구 1 | Make | 자동화 구현 |
| 자동화 도구 2 | Zapier | 동일한 자동화 구현 |
| 알림 | Gmail | 담당자 알림 전송 |

## 4. 설문 구성

| 문항 | 형식 | 활용 목적 |
|---|---|---|
| 참여자 이름 | 단답형 | 응답자 구분 |
| 참여 프로그램 | 드롭다운 | 프로그램 분류 |
| 참여 날짜 | 날짜 | 참여 일자 기록 |
| 전체 만족도 | 1~5점 | 불만족 응답 판단 |
| 상담 필요 여부 | 예/아니요 | 상담 요청 판단 |
| 상담 내용 | 장문형 | 담당자 확인 |

## 5. 자동화 조건

- 만족도가 1~2점이면 긴급 확인 대상으로 분류한다.
- 상담 요청이 '예'이면 상담 요청 대상으로 분류한다.
- 위 조건에 해당하면 담당자에게 이메일을 보낸다.
- 일반 응답은 Google Sheets에만 기록한다.
